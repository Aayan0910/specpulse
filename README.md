# SpecPulse India — PC Hardware Price Comparison & Configurator

SpecPulse is an open-source, ultra-low-cost PC hardware price comparison engine, historical tracker, and PC builder specifically designed for the Indian enthusiast market.

## ✨ Features

- **Live Multi-Retailer Price Tracking:** Compare real prices across Amazon India, Flipkart, MDComputers, PrimeABGB, and Vedant Computers.
- **Historic Price Tracking & Drops:** Identifies true discounts against 30-day moving minimums (not inflated crossed-out MRPs).
- **Interactive PC Builder:** Real-time socket, RAM type, dimension clearance, and wattage compatibility engine.
- **Benchmark Comparison Matrix:** Head-to-head GPU and CPU gaming performance metrics in 1080p, 1440p, and 4K.
- **₹0 Monthly Running Cost:** Designed strictly within the ₹100 INR/month ceiling using Vercel, Neon DB, and GitHub Actions free tiers.

## 🚀 Quickstart

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run Development Server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` to view the application.

3. **Run Typecheck & Build:**
   ```bash
   npm run build
   ```
